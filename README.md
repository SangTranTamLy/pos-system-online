# POS System Online Pickup

## Mô tả
Hệ thống POS tích hợp đặt hàng online và nhận tại cửa hàng.

## Công nghệ sử dụng
- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Express, TypeScript
- Database: Supabase

## Trạng thái hiện tại
- Frontend chạy local thành công
- Backend chạy local thành công
- Supabase Health Check API thành công
- Đang ở giai đoạn phân tích bài toán và chuẩn bị kiến trúc

## Cách chạy project

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

## Ghi chú
File `.env`, `node_modules` và tài liệu nội bộ trong `docs/` không được push lên GitHub.
